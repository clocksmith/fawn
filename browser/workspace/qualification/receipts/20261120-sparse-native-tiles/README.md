# Sparse canonical evidence for restricted I420 frames

On a 512 × 256 Rec.709 frame, changing one luma sample inside a 64 × 64 tile required 16,384 bytes of canonical RGBA output and 16,384 bytes of SHA-256 input. A U or V sample at a four-tile boundary required 65,536 bytes each. An unchanged authorized frame required zero. The initial full conversion returned 524,288 bytes and hashed 1,048,576 bytes across the full-frame SHA and its 32 tile hashes. The underlying C++ cache still compares native planes. It copied one changed luma row (512 bytes) or chroma row (256 bytes) into its owned I420 snapshot in these cases. These counts describe delivered buffers, hash inputs, and explicit snapshot writes. Internal Skia conversions, memory traffic, GPU sampling, elapsed time, and power savings remain unmeasured.

The optional patch applies after the ninth restricted-I420 overlay. The native method binds a closed prior VideoFrame wrapper to the same live restricted capture cache and isolated world. It also checks the last serial, capture version, storage, layout, native scale, transformation and color metadata. New and resized captures and changed samples outside the supported sparse geometry require a complete conversion. The restricted path accepts directly readable tightly packed even I420, Rec.709 SDR, power-of-two tile sizes from 16 through 256, and up to 256 tiles. The existing whole-frame proof remains available for other eligible SDR color spaces. A rejected partial conversion falls back to the same held frame's full conversion. The public observation carries ordered hashes, and a successful sparse update leaves the optional whole-frame digest absent.

The pinned renderer's unscaled I420 CPU paint selects libyuv's unfiltered matrix conversion in media/gfx/paint_canvas_video_renderer.cc. The native comparison covers each changed luma pixel and the corresponding 2 × 2 chroma footprint with one additional chroma sample on each edge. Both frame and tile crop origins are chroma-aligned. A CPU regression reconstructs the new frame from the old full image plus the native plan's freshly rendered crops and compares every RGBA byte to a complete sRGB Skia paint. The tests cover nonuniform planes, 512 × 256 and 514 × 258, right/bottom edges, separate leases, resize, crop, scaling, retirement and the recorded external-sampler chroma collision across all 32 tiles. The real stock WebCodecs test independently checks the production digest consumer and full-frame oracle using the same inputs and specified masks. Its masks are fixture inputs. The native producer is exercised in the separate pinned C++ test.
