# Benchmark regression controls

Inherit [benchmark instructions](../AGENTS.md) and [test-value rules](../STYLE.md#test-value).
Use synthetic receipts and independent expected outcomes. Preserve meaningful
negative controls for wrong units, missing evidence, stale artifacts, unknown
machines, callback failures and accidental qualification.

Test public consumer behavior, not source spelling or copied policy literals.
Run affected modules; hardware campaigns are separate acceptance evidence.
