# Retained Fawn benchmark fixtures

These five pages are active inputs to the fresh-launch and browser lifecycle or
layered diagnostic harnesses. They are excluded from CanvasContext and native
product packages. Their move does not count as deleting workload code.

Fluid fixtures import the canonical product solvers and keep their distinct
rendering and interaction behavior. `formation-material.js` holds their legacy
transported-sheet helpers. Other workloads retain their own independent kernels.
The fresh-launch server records every served source hash. Layered rows bind the
fixture and declared module dependencies; source changes require new receipts.

Historical receipts retain original filenames, paths and hashes. The pre-move
source is available at Fawn commit
`bd4aaf55944df1085227b78b8c67b3f228266281`; historical evidence is unchanged.
