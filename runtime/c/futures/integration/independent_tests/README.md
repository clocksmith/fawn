# Independent retained-native C futures suite

This compact test package does not vendor the runtime. It requires an explicit
current pinned Doe checkout and verifies 251 source/header/license inputs before
copying their import closure into a new output directory. Repository files are
never edited. The real native lifecycle and callback implementations are used;
there is no queue/refcount/free model or archived-source dependency.

Run on Linux x86-64 with existing Zig 0.15.2, GCC/G++, Python 3 and Vulkan loader:

    python3 run.py --repo /path/to/doe --zig /path/to/zig-0.15.2/zig \
      --vulkan-lib-dir /path/to/loader/lib --out /tmp/futures-independent

--prepare-only verifies/copies inputs and records exact commands without building.
--mode asan or --mode tsan instruments only GCC C futures/bridge, not retained Zig.
Add --native-library /path/to/libwebgpu_doe.so to build and execute the public-header
C/C++ consumers against that explicitly supplied prebuilt shared library.
Alternatively add --build-shared (normal mode) to build the actual selected
headless shared artifact from 366 additional hash-verified source inputs, then
run the C/C++ consumers. No production source copies ship in this package.

build_options.fixture.zig is a frozen source-derived TEST fixture, not a new
production policy owner. Its bytes were generated by the real runtime/zig/build.zig
selected headless ReleaseFast configuration at the implementation seal, then used
by all independent builds. The generated fixture is included (39,830 bytes), so
no private cache or previous artifact is required. --build-options may provide the
same verified bytes explicitly. A changed source or policy requires a new reviewed
fixture/manifest, not bypassing the check or claiming current-policy coverage.

Normal expected result: 12 active tests pass and the deliberate fatal guard skips.
To exercise the guard separately, run EVAL_BUSY_QUEUE=1 OUT/independent_tests;
expected SIGABRT with queue deinit status 8. Never reinterpret this as cleanup.

The C injector is compiled with gcc -std=c11 -O2 -g -fPIC -shared -Wall -Wextra
-Werror -Wpedantic pthread_faults.c -ldl -o OUT/pthread_faults.so. Use LD_PRELOAD
and EVAL_PTHREAD_FAILURE with the C native consumer. It arms only around actual
native calls, after dlopen. mutex-init, attr-init, attr-clock, cond-init with the
consumer's expect-null argument must return NULL; attr-destroy, cond-destroy,
mutex-destroy, or cond-init,mutex-destroy without that argument must abort status13.

PROVENANCE.md records the frozen evidence scope and independent test authorship.
The fixture, manifests and all helper sources are included; no binaries, archive,
compiler/cache or copied production source is included in this compact package.
