# Resource ownership

Follow the common C guide and parent charter. This owner adopts real native
resources; never create a synthetic backend or publish borrowed native storage
as owned. Preserve same-device identity, transactional acquisition, first-error
recording and unknown-submission obligations. Keep map/future delivery, labels
and diagnostics in their existing owners. Normalize named format semantics at
native ABI adapters: retained Zig/header numeric identities currently differ.
The focused check is `make -C runtime/c/resources check`; outputs belong in `/tmp`.
Render attachment begin/end packets must bracket every query event, including
empty scopes. Never infer pass closure from the last draw. Map completion pointers
start at the admitted span; const/read admission must not become writable storage.
Bundle replay clears logical bindings even for zero bundles; do not copy retained
Vulkan's internal save/restore into public state. Keep each bundle self-contained
and reuse pass draw admission and packets rather than another renderer.
Float32 filterability is an enabled WebGPU feature, not a driver capability.
Keep copied binding feature admission in the group owner through submission.
Shared dispatch/draw scope validation owns cross-binding aliases: buffer usage is whole-object,
while writable storage aliases additionally use resolved byte ranges. Never replace
this with backend handle equality or frontend-only pair checks.
Render-pass scopes include every setter and executed bundle, even overwritten,
unused or empty ones. Transfer retained scope storage to immutable end records;
logical unbind/reset must not erase usage. Query descriptor count is 0..4096;
zero-count logical identities need no native pool but cannot write or resolve.
Nullable vertex unbind validates its zero buffer range without deleting historical
scope uses. Occlusion indices are single-write per pass, not per command buffer;
keep this logical admission separate from backend query reset/availability.
Shader binding alias checks compare shared stage visibility; whole render usage
history does not. NULL/empty pipeline-layout slots share required-group admission;
materialize absent/trailing getter layouts only through the canonical owner with
status and untouched-output failure semantics, never a frontend cache.
Keep occlusion event order and exact pool identity in native pass spans. Native
reset/availability remains the backend's responsibility; no synthetic results or
second query-state map. Software zero/nonzero evidence is not precise samples.
Keep baseline format/aspect scalar classification in the canonical format owner.
Optional filterability, backend support and renderability remain separate admission;
do not infer them from a Float class or duplicate the stencil-only rule in adapters.
Clear values are ignored unless the corresponding load operation is Clear.
Do not let finite/range checks on unused values contradict the public descriptor;
actual native scalar conversion remains checked at its representation boundary.
Normalize zero-entry pipeline layouts before automatic exclusivity; no empty
layout identity may accidentally claim a pipeline. Preserve true vertex holes
(Undefined mode and no attributes) versus explicit empty required slots. Direct
bounds use first+count, not count alone; never infer GPU indices on the host.
Frontend rejection must poison the existing pass/bundle owner explicitly.
Absent or read-only attachment aspects require undefined operations. Transient
constraints span texture creation, view usage and pass Clear/Discard admission;
keep them canonical without pretending host retention proves native memoryless use.
Resolve destinations are retained attachment writes in the same pass scope,
including empty passes and bundle replay. Never resolve each draw independently
or omit a destination merely because a backend adapter cannot yet consume it.
View layer defaults depend on resolved dimension, and view format defaults on
selected parent aspect. Binding usage remains the parent subresource identity;
renderability requires all actual parent aspects, not the literal All enum.
Debug nesting belongs to each existing recording owner. Keep parent/child stacks
independent, preserve sticky errors and require balance at end/finish. Optional
diagnostic labels must not introduce another string store or resource command queue.
