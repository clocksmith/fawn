is occupying the host. Re-evaluate host/storage availability before later runs.

## Initialization and configuration

8. Fresh-process behavior: unset/empty/invalid lane, every accepted canonical name,
   accepted-but-unconfigured names, ASCII uppercase/hyphen spellings, alias,
   canonical-versus-alias key disagreement, too-long lane and whitespace. Change
   environment only sequentially: before first use versus after first behavior
   publication. Environment read must be zero without laneModes object and once
   with a valid object, even empty. Never use concurrent getenv/setenv as evidence
   of portable publication behavior.
9. Cold concurrent manifest hits/misses, same/different names, behavior-only and
   ownership-only calls: no partial result, deadlock, duplicate publication or
   leaked caller string. Required-proc's existing g_state_lock -> C lock path
   must terminate under contention. Instrument platform boundaries or explicit
   private read-only counters; no public reset/mutation testing API. Repeat with
   short-lived lookup buffers overwritten after return and immutable descriptor
   storage separately demonstrated. All calls must end before DSO unload.
10. Lazy death cases: invalid string modes (selected/unselected), both invalid
    default and lane mode, ownership mismatch in an UNUSED row and a LATER
    duplicate row. Manifest hit must bypass ownership fatal; a manifest miss must
    validate all rows. Invalid/null/explicit-empty view initializes behavior only;
    sentinel-empty is a valid empty name and can trigger ownership. Pin the newly
    specified ownership-first combined-fatal ordering as a deliberate delta,
    not an invented preexisting guarantee. Compare fatal classification/text,
    not platform panic backtrace or one fixed signal number.
11. Behavior corpus: malformed/nonobject, missing/wrong-type strict, missing/
    wrong-type/unknown default, strict true/false, string/nonstring lane members,
    nonobject laneModes, schemaVersion ignored, unknown fields, duplicate keys
    including unused nested objects, trailing bytes, UTF-8/surrogate/escaped-NUL,
    syntactically valid giant integer/exponent tokens and invalid NaN/Infinity.
12. Ownership corpus: version2/3/other, missing/wrong known fields, known-key
    duplicate versus ignored-key/nested duplicate, unknown tier/fields, mixed-case
    owner, bad token, partial valid-prefix rejection, duplicate/empty/exact-case
    symbol and active-tier mismatch. Seal explicit old/new cases for quoted/
    floating schemaVersion and byte-array symbol/owner (including byte coercion),
    rejected lazily only by profile1. Confirm no additional semantic tightening.
13. Generator boundary: empty and 64KiB inputs, over-limit/read failure distinct
    from invalid config, nesting beyond Python default recursion without recursion
