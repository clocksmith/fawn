# CATSCAN: Experimental C drop-in policy

Parent: [Experimental C migration](../CATSCAN.md)

## Target
Own embedded-configuration interpretation and process-once native route decisions in independently usable C.

## Authority
- Owns behavior/ownership publication, environment capture, symbol ownership and route policy in the explicitly selected path.
- Retained native manifest and backend declarations own identities; native resolver and diagnostics own proc loading and observations.

## Scope
- Includes the GCC-only owner, deterministic config generator and reversible native adapter defined by the frozen contract.

## Contracts
- Inputs: [contract](CONTRACT.md), [source identities](SOURCE_INPUTS.json) and [header](include/doe_dropin_policy.h).
- Output: explicit route/status records without runtime Zig policy delegation.

## Invariants
- Default production remains retained Zig; no hidden fallback or duplicate selected policy state.
- Borrowed descriptors are immutable for provider-image lifetime; no caller lookup pointer is retained.
- Deliberate admission/failure differences remain explicit; CPU address lookup does not qualify hardware or cure an unproven Debug failure.

## Acceptance
- Independently sealed semantic, concurrency, generator and actual native consumer gates pass before acceptance.
- Evidence: [acceptance obligations](ACCEPTANCE.md); current state: [README](README.md).

## Non-goals
- Native proc implementation, sidecar ownership, diagnostic storage, device lifetimes, physical backend qualification or production-default promotion.

## Freedom
Any implementation is permitted if it preserves these boundaries and passes the acceptance evidence.
