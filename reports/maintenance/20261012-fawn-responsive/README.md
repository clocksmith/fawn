# Fawn canvas sizing, particle frame and Flow material

Component: hosted Fawn artwork under `browser/chromium/resources/`.
Intent: changed as requested. Remove the Particles canvas focus frame and lift
Flow's dim pigment while keeping colored highlights and finer local contrast.
Acceptance evidence: [responsive.json](responsive.json), generated by
`browser/chromium/scripts/test-fawn-responsive.js`.
Boundary effects: HTML/CSS and Flow's display shader; no particle simulation,
fluid solver, native runtime, browser binary or hosting-route changes.

The regression reproduces a solid outline on the preceding Particles canvas
with actual keyboard focus. The candidate retains focus and arrow-key input but
has no canvas outline, border or shadow. Toolbar controls retain focus outlines.

All three hosted pages cover their viewport at the recorded sizes and pixel
densities, including paused rotation. Backing resolution preserves aspect and
respects the device texture limit. Flow and Wave also check backing size on active
frames so a pixel-density change updates the canvas without rebuilding simulation
buffers. The existing lifecycle suite separately exercises constrained device
limits, initialization and terminal cleanup.

Flow reuses four dye samples for interpolated relief and mild local contrast.
Exposure lifts dim colors and rolls highlights off; the uniform background keeps
the perimeter from becoming black. The report compares GPU pixels from identical
retained shader inputs, checks brighter pigment and rejects clipped highlights.
It does not establish conservation, performance improvement or arbitrary hardware
support. The square-world render oracle also passed for all three pages in wide,
portrait and square viewports; its local screenshots remain outside Git.

Reproduce from the Doe root with `FAWN_PLAYWRIGHT_MODULE` pointing to an installed
Playwright ESM module:

```sh
node browser/chromium/scripts/test-fawn-responsive.js
node browser/chromium/scripts/test-fawn-square-world.mjs
node browser/chromium/scripts/test-fawn-canvas-lifecycle.mjs
```

On macOS, set `FAWN_CHROME_ARGS='["--enable-unsafe-webgpu"]'` for the latter two
checks. These are Chrome WebGPU application checks on the recorded Apple adapter;
emulated screen sizes are not physical-phone or forced-Doe qualification.
Publication is separate; CanvasContext's release manifest identifies live bytes.
