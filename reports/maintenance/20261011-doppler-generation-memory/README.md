# Installed Node generation and sampled-logits ownership

The frozen [policy](policy.json) measures a retained generation case against its
[independent CPU reference](reference.json), with unchanged model bytes,
precision, context capacity and output requirements. Both exact standard
Doppler archives run through an explicitly selected Doe or Dawn Vulkan provider.
The [manifest](manifest.json) authenticates packages, source delta, hardware,
producer snapshots, full cohort, failures and earlier invalid observations.

The localized allocation growth belongs to Doppler's sampled-logits consumer.
It received a CPU readback and an owned GPU logits buffer, then discarded the
GPU reference after sampling. Replay decode repeated this omission. The repair
releases that buffer in `finally` and routes replay sampling through the same
owner. Explicit GPU-only output and advanced decode APIs still transfer their
buffer to the caller. Tensor math, sampling policy and Doe pooling are unchanged.

Baseline active buffers grow after each answer and cancellation. Candidate
active bytes and count return to the loaded capacity on both providers; retained
weights stay unchanged. Regression tests cover success, sampling failure, decode
failure and subsequent reuse. The complete unit, source architecture and style
checks pass. Installed output, cancellation, following generation and teardown
pass before profiling and measurement.

The [complete comparison](summary.json) fails primary process-RAM admission.
Requested-buffer capacity improves, but peak process RSS does not improve enough.
Foreign Chrome GPU work is recorded in every measured process; those timings
cannot qualify an advantage. The Doe load-latency regression bound also fails.
No processes were discarded and no favorable retries were selected.

Retain the proven ownership correction as a resource-lifecycle repair. Reject a
material RAM or speed claim. This result does not establish faster inference,
unique physical GPU-memory savings, or readiness to promote browser contribution.
Reploid integration and unrelated-application memory transfer remain gated on
local advantage. Older rejected runtime experiments retain their verdicts.

The observer separates host process RAM, requested live WebGPU buffers, Doppler
retained/active/reusable capacity and raw DRM client residency observations.
It does not combine them into physical memory. Final teardown requires queue
settlement and destruction; the idle observation window is not a cleanup rule.
Cold shader directories are fresh for every process; OS file cache is uncontrolled.

Reproduce with `run-memory-cohort.py <policy> <baseline-provider-manifest>
<candidate-provider-manifest> <new-output-directory>` from the repository root.
Run `analyze-memory.py <policy> <cohort-directory> <summary>` on the complete cohort.
`run-memory.mjs` rejects measurement without an exact matching successful
qualification receipt. Provider paths and local model custody are explicit in
the retained manifests. Archives are local evaluation custody, not a registry
release. The Doppler packages have no workspace dependency symlink; the selected
source-bound providers remain separately pinned.

Validate retained evidence with `validate-memory.py <report-directory>`.
Add `--local-archives` on the artifact custodian to authenticate evaluation archives.
