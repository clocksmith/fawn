# Particle reset clears gesture state

Component: Chromium-hosted Fawn artwork.
Intent: preserved; reset clears previous interactions while preserving pause,
Count, Steps and Formation.
Acceptance evidence: `before.json` and `after.json`, generated by
`browser/chromium/scripts/test-fawn-particle-clock.mjs`.
Boundary effects: CanvasContext's existing hosting projection publishes the page.
No shader, projection, native runtime or browser-binary changes.

Reset reseeded the particle buffers and cleared time, but retained the previous
gesture's filtered force. Reset now clears active input and its force alongside
the particle state. The same reset path applies when Count changes.

The preceding-source report reproduces the stale force after a paused reset.
The corrected-source report checks cleared force and time, preservation of pause,
and resumption without the old gesture. It also retains the clock checks for
paused redraws and equal model time across frame partitions and Steps choices.
Each report binds its source and browser/adapter identity.

These are controlled-clock application checks with actual Chrome WebGPU
submissions. They are not performance measurements, physical-phone validation,
or qualification of native Doe or the Fawn browser binary.

Reproduce using `FAWN_PLAYWRIGHT_MODULE`, `FAWN_CHROME_ARGS`,
`FAWN_REPORT_DIR` and optionally `FAWN_TEST_ORIGIN` with the script above.
