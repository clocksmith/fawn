# Fawn-Doe Matrix Reports

Tracked synthetic reports were removed because they exercised decision rules but
did not measure browser or runtime behavior.

Admissible evidence must be generated by the live executor in
`bench/fawn_matrix`, pass its evidence validator, include all four lanes, and cover
both Apple Metal and AMD Vulkan on distinct physical machines. Generated artifacts
remain under `bench/out/fawn-matrix/` until independently reviewed for publication.
